# 插件管理页面（Codex 风格）

路径：`codex-ui/src/components/Sidebar/BuiltinPluginsTool.tsx`

## 设计和交互

- **紧凑列表**：不再把每个插件直接展示成大块操作表单。按桌宠、压缩、文档转换分组，图标、状态和开关直接显示在列表。
- **搜索与状态筛选**：通过插件名称、ID、描述、所属类别搜索；可切换「全部 / 已启用 / 未启用」。
- **按需展开**：点击插件名称或右侧箭头，才显示依赖、运行状态、命令及操作表单；一次展开一个插件。
- **快捷开关**：列表右侧开关调用现有 `/api/plugins/bundled/enable`，保持用户确认与后端权限验证。
- **执行操作**：运行桌宠 / 压缩 / 转换仍调用原有 `/api/plugins/bundled/execute`，并且每次显示确认框；不改动插件协议。
- **窄屏适配**：插件侧栏在宽屏约 352px，其他模块仍保持原来的 294px，窄屏按可用屏幕收缩。
- **主题一致**：单独 `builtin-plugins.css` 仅作用于插件面板，使用 `--card-bg`、`--fg`、`--border-10` 等已存在的主题变量。
- **可访问性**：搜索标签、过滤按钮状态、展开状态、开关 `role=switch`、刷新控件与反馈提示均带可访问标签。

## 注意

该页面只改变前端表现，不自动下载依赖、不改变后台授权逻辑，也没有引入 Codex 的受版权保护图标、代码或页面文件。仅参照其简洁、低干扰的工作区交互语言。

## 验证

`node --test test/plugin-panel-ui.test.js`、`cd codex-ui && npm run build`；完整 Windows 界面仍需要本地构建后人工检查。
