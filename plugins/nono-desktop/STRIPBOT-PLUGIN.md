# 糯糯 3D 桌面宠物插件 v0.3.1

在 Strip Bot 中打开「设置 → 桌面宠物」启用。使用 Strip Bot 已有的 Electron 桌面引擎，不再需要 Python；Three.js 0.180.0 渲染库及许可证随包提供，3D 场景离线加载。

本版接入 nono_action_project.zip 中的 GLB 模型与 14 段动画，使用本地 Three.js 和 GLTFLoader 离线加载。动作控制器支持切换与中断，保留透明独立窗口及原有提问功能。

- 拖身体：移动桌面窗口。
- Alt + 拖身体、方向键：旋转观察。
- 拖小手后松开：弹簧回弹。
- 双击：打开提问窗口。Enter 发送，Shift+Enter 换行，中文输入法选词不会发送。
- 右键：挥手、跳跃、玩球、睡觉、大小、置顶、待机动画、休息提醒、退出。
- 右键 → 更多动作：跳舞、转圈、捂脸、伸懒腰、鞠躬、摇摆、击掌、大跳、组合动作、随机动作及停止复位。
- 按住空格蓄力，松开跳跃；离开窗口会取消蓄力。等待击掌时点击小手或按 H 回应。

问答继续使用 Strip Bot 已保存的 API Key 连接及模型，支持 Chat Completions / Responses。尚未接入 CC Switch 或 ChatGPT 账号问答。密钥留在后端，宠物仅持有启动令牌；没有配置时会提示先保存连接。真实模型请求会使用服务商额度。

输入上限 4000 字，最近 10 轮仅在内存保存；单条回复用于后续上下文时保留前 4000 字，本轮显示上限 16000 字。关闭提问窗口会隐藏窗口并保留本次运行的对话，退出宠物后清除。不读取主窗口聊天记录，不执行命令或修改文件。

设置中关闭会终止插件，主程序退出后宠物也退出。启用偏好会保存，下次启动宿主自动恢复。START_NONO.bat 仅通知运行中的宿主启用插件。

旧版 Python 图片玩偶文件保留供对照，不再作为插件入口。实际入口为 desktop.cjs；pet.html 为离线适配的原始 3D 场景，chat.html / chat.js 为提问窗口，preload.cjs 只提供有限 IPC。

验证：19 项相关 Node 测试；真实 WebGL 渲染 9 个部件、38914 个三角形；14 段动画切换后的姿态数值检查；击掌计数、失焦取消蓄力、提问窗口模拟回复与退出回收通过。动作检查为抽样检查，未逐帧验收全部动画，没有调用真实服务商做计费测试。

响应修复：单击可打断正在播放的动作，动作切换淡入从 180ms 缩短至 80ms。
