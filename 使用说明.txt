Page07 · 澄 Local Chat

1. 双击 start-windows.bat：启动软件并打开浏览器。
2. 点击右上角设置，填写本机 API 地址、模型名，检测连接并保存。
3. 双击 stop-windows.bat：停止本目录启动的服务。

软件地址：http://127.0.0.1:3060
需要 Node.js 18 或更新版本；不需要安装 npm 依赖。

没有模型时，可双击 start-demo-windows.bat 体验消息收发。
演示接口仅回显消息，不会产生真实 AI 回复。
使用默认设置即可连接演示接口。切换真实模型前先停止演示服务。

支持 OpenAI 兼容、Ollama、普通 JSON 本机接口。
聊天记录和设置保存在当前浏览器中。
启动日志在 .runtime 目录；详细接口说明见 README.md。
这是浏览器界面加本地 Node 服务版本，未打包为独立 EXE。
