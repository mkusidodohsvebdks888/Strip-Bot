> 注意：此目录仍是独立源码备份。现通过 `plugins/deepseek-harness-pet/` 提供 **StripBot 插件适配器**：在本机已安装可信的 Windows EXE 后，可从左侧插件中心确认并启动桌宠。插件不会自动安装、下载或把原始源码复制一份，也不代表桌宠现已使用 StripBot 的聊天 API。桌宠仍需 DeepSeek Harness 的本地会话日志才能显示任务进度。
