# 背景素材

**独立保存的 UI 样式素材库**，适合为 React、HTML、桌面应用的 Web 界面挑选背景。此目录与 StripBot 的业务源码分开存放，不会自动修改或覆盖原有界面。

## 📁 分类

| 分类 | 目录 | 内容 |
| --- | --- | --- |
| 经典毛玻璃 | `01-经典毛玻璃/Nimu-Glass-UI/` | Nimu Glass UI CSS 与 MIT 许可原件 |
| 液态玻璃 | `02-液态玻璃/GlassKit/` | GlassKit CSS、主题覆写样式与 MIT 许可原件 |
| 纹理背景 | `03-纹理背景/Uiverse-Patterns/` | 三个精选背景纹理 HTML 示例与 MIT 许可原件 |
| 独立 CSS | `04-独立CSS样式/` | 不需要安装依赖的 8 种背景/面板风格 |
| SVG 图片背景 | `05-SVG背景/` | 柔和极光、细线网格、点阵背景 |
| 本地浏览预览 | `预览.html` | 打开即可查看八种独立 CSS 样式 |

## 独立性与更新规则

**这里的第三方样式是实际复制进 GitHub 的静态文件。** 不是 Fork、Git 子模块（submodule）、远程链接或运行时 CDN 引用。上游作者修改、更新或删除原项目，**不会自动影响此目录**。只有你或有写入权限的人主动提交更改、执行同步脚本或手动合并时，本仓库内容才可能改变。

每一套来自 GitHub 的文件都标记了原始仓库、固定来源提交并保留 LICENSE。复制发生在独立文件夹；原始作者的开源许可和署名依然有效。

## 使用方法

1. 下载本目录，直接用浏览器打开 `预览.html` 查看独立背景效果。
2. 只想要不影响页面其他元素的背景：引入 `04-独立CSS样式/背景合集.css`，使用 `.sbg-aurora`、`.sbg-glass` 或 `.sbg-liquid` 等类名。
3. 需要整套第三方组件时，再按对应目录 `来源说明.md` 引入 Nimu Glass UI、GlassKit 或 Uiverse 图案。**不要在未测试时将两个完整组件库同时全局引入**，以免 CSS 选择器冲突。
4. SVG 可以直接作为 `background-image: url(...)` 的本地资源使用。

> 说明：这是素材库与源码副本，不是已经自动安装好的 StripBot 主题切换器。仓库中保存了源文件，但当前没有直接改写 StripBot 的界面样式或前端构建脚本。
